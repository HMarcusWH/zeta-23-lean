# Mathematical glossary and historical terminology crosswalk

Version 1 — 28 October 2026. This is a navigation crosswalk for the current
source lineage, not a new mathematical specification. RH and Step 4 remain OPEN.

The project has reused letters and metaphors across different campaigns.
Resolve a label through its dated document, actual source object and exact
theorem before transferring a result. A similar name is not an equivalence.
The [project guide](PROJECT_GUIDE.md) explains the programme in connected prose;
the [framework guide](FRAMEWORKS.md) covers the evidence and governance systems.

## Mathematical objects and symbols

| Term | Meaning in this programme | Scope to retain |
| --- | --- | --- |
| RH | Every actual nontrivial zeta zero has real part `1/2`. | The terminal conjecture is OPEN. A theorem with an explicit RH-strength premise is conditional. |
| `rho` | An element of the repository's actual nontrivial-zeta-zero carrier. | A synthetic off-line atom is a control, not such an element. |
| `lambda = rho - 1/2` | The shifted complex coordinate used by causal Laplace obstructions. | Distinct from a real spectral shift also named `lam` in finite resolvent theorems. |
| `kappa = rho(1-rho)` | The spectral coordinate used by zero profiles and sampling. | It is not the shifted coordinate `lambda`; off-line applications retain their nonreal-domain conditions. |
| `L` | Physical aperture in the canonical finite/contact programme. | It is not automatically the physical observation time `T`. A scale change needs its adapter. |
| `K` | Finite Fourier cutoff for the actual canonical matrix/carrier. | It is not a common global cutoff for every aperture unless the theorem says so. |
| `Theta` | The actual supremum of nontrivial-zero displacement from the critical line. | The [native cuts](../Zeta23/OPICARound2/NativeCuts.lean) relate `Theta=0` to RH; they do not prove it. |
| `beta` | Often an exponent with `0 < beta < abs(Re(rho)-1/2)` in the Step123 producer. | The walkthrough's `alpha,beta` instead name two real ground energies locally. Other source multipliers also use Greek letters. Read the declaration. |
| Physical carrier | The actual finite function/subspace with inherited inner product, parity, boundary and pole-neutral constraints. | An arbitrary coordinate space with a convenient norm is not automatically the same carrier. |
| Complete canonical form | The unchanged canonical Weil form with pole, Archimedean and all active prime-power contributions and its correct normalization. | A principal minor, source term or diagonal-correction-free proxy needs a proved bridge. |
| Complete corrected source | The source functional after the actual neutral compression, retaining its output correction. | A source-only kernel statement cannot omit the transferred operator output on a general Schur witness. |
| `D` in parity transport | The actual invertible even-to-odd index map, with its genuine adjoint in the odd orientation. | Generally nonunitary; distinct from cutoff inclusion and from differential-operator notation. See [neutral geometry](../Zeta23/CCM/CanonicalPoleNeutralGeometry.lean). |
| Ground / bottom | The least Rayleigh energy and corresponding genuine eigenmode on the specified physical carrier. | A D05 negative Schur witness is not automatically that eigenmode. Its normalized energy can bound the bottom. |
| Shared negative ground | Equal even and odd bottom energies, both negative, at the same `L,K`. | Strict below-opposite-spectrum formulas do not cover this branch. |
| Same-state / same-source | A proved lineage connecting the same selected packet and its mathematical views. | Track aperture, cutoff, phase, normalization and maps. The views may contain different vectors. |

## CI lanes and evidence words

A **lane** is an evidence-producing job group with a declared source identity
and scope. It is neither a mathematical Path nor a historical Pair.
The [current workflow contract](../research/RHRC/integration/opica_round4/WORKFLOW_CONTRACT.json)
and [exact acceptance inventory](../research/RHRC/integration/opica_composition/accept.py)
define the lane names, rather than this glossary.

| Current lane vocabulary | Role |
| --- | --- |
| CONTRACT | Static source, schema and inventory checks. |
| PARENT_REGRESSION | Preserve the frozen parent result on its declared historical scope. |
| CURRENT_COMPATIBILITY | Check inherited formal interfaces on the actual current source. |
| COMPOSITION_FORMAL / SEMANTIC_NEGATIVES | Check generated terms and independent consumers; reject the intended stronger or wrong applications. |
| FRAMEWORK_ADAPTERS / PROVIDER_SELECTED | Check scoped integration and the selected external provider interfaces. |
| REPLAY_CAMPAIGN / GENERATED_STATE | Reconstruct the declared runs and generated products with their identities. |
| MATHEMATICAL_SUPPORT | Check the new supporting declarations and their actual assumptions. |
| SOURCE_NUMERICS | Produce independently checked finite arithmetic dispositions. |
| ACCEPTANCE | Independently combine the required lane evidence; it is not its own upstream input. |

**PROVED** refers to an exact accepted declaration and its hypotheses.
**DERIVED** is a consequence not separately formalized. **LEAD / HYPOTHESIS**
is an unproved route. **EXPERIMENTAL SIGNAL** is scoped numerical/search
evidence. **OPEN** means not established. A failed, missing, pending or skipped
gate remains that disposition; a regression replay preserves its previous result.
An interval certificate, a Lean theorem, release acceptance and independent
human review have separate authority. The [agent instructions](../AGENTS.md)
give the continuing post-green research and claim-firewall rules.
