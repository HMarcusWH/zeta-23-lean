# RHRC parallel closure campaign

This directory is the executable research-control layer for PR #274.

It deliberately separates Lean theorem authority from research execution,
execution status from evidence integrity, and research disposition from any
terminal RH claim. It also keeps the three distinct tails separate:
archimedean integration, Fourier mode, and aperture.

PLAN.json freezes the actual A/B/C/D parameter schedules. The scripts are
checked against that plan in CI; changing a hard-coded research scope without
changing the plan is a test failure.

The four tracks are harvested together in HARVEST.json. Categorical research
dispositions remain categorical. Only rigorous bounded real intervals from
Tracks A/B/C enter CLOSURE_NUMERICAL_RECEIPT.json; Track D's
floating/synthetic masking work is deliberately excluded from interval
authority. The numerical receipt binds the exact source commit/tree, plan,
scope/fixture digest, program digest, precision schedule, case parameters and
outward dyadic intervals.

A green campaign with all tracks still open is a valid result. Only an exact
premise-free theorem of Mathlib RiemannHypothesis can change RH_OPEN.
