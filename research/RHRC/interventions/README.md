# Intervention battery

Each intervention declares:

1. changed object;
2. held-fixed objects;
3. predeclared property tested;
4. interpretation boundary.

Initial families: `J_aperture`, `J_probe_family`, `J_support`, `J_moment_information`, `J_prime_family`, `J_delta`, `J_gamma`, `J_phase`, `J_cluster_spacing`, `J_multiplicity`, `J_candidate_remove`, `J_null_family`, `J_window`, and `J_all_conditional_inputs`.

An intervention or ablation is diagnostic. It does not by itself prove mathematical necessity or causality.
