# Governed deduction for OPICA Round 4

This implements `ROUND4_GOVERNED_DEDUCTION_V1` around the retained
`THREE_FRAMEWORK_INTEGRATED_V1` contract. The reviewed parent is PR #297,
`fe16565b2a31fb8b68bef916ae8f04d535880e7a`. Runtime evidence is external to Git.

The proposer emits a finite expression grammar, never Lean source, tactics,
commands or imports. Trusted drivers elaborate against independently specified
targets; the kernel, full axiom/dependency audit and fresh expected-type consumer
must all succeed. Conditional hypotheses remain in the resulting proposition.
The two mandatory calibrations compose the actual D02→D05 and D02→D04 theorems.
They reproduce established conditional results and are not independent research.

`composition_search.py` additionally retrieves multi-step applications, scoped
dependent witnesses, conjunction/existential elimination, both disjunction
branches and shared intermediate packets from compiler type DAGs. The reviewed
`SEARCH_CONTRACTS.json` adds three actual non-calibration targets without changing
the frozen462-declaration atlas. Fresh compiler exports verify the retrieval
contracts in the native acceptance lane. Proof terms are erased only for retrieval
using compiler-classified proof constants; full types and instances are rechecked
by Lean. Universe erasure and retrieval matching grant no proof authority.

Search stops at explicit state, depth and candidate budgets. A resource stop can
still yield a frozen partial menu for independent checking; it never means that a
goal is unprovable or that the mathematical search was exhaustive. Replaying a
plan reconstructs the same source-bound bounded menu before dispatch.

Linux production workers require read-only project/package/toolchain mounts,
an empty environment, isolated network/process namespaces, bounded process
resources, a hard 4 GiB cgroup memory ceiling and a hard 4 GiB tmpfs output
volume. Windows execution is development evidence only. Missing native setup
fails its lane; native tests do not skip.

`Journal` maintains a transactionally verified event chain, durable attempt
counts, frozen menus, compare-and-swap revisions and archived stale results.
Native publication repeats the independent checker and reconstructs all four
FFBBP gates. OoL graph ports come from the native dependent proof packet and
its exact local context. Policy priorities do not grant mathematical authority.
The separately pinned Lean 4.34 Permansson provider qualifies three selected
interfaces only; host Lean 4.33 objects and provider objects never mix.

`EXPECTED_TESTS.json` binds every method to one lane. All 117 original cases
are retained, with explicit file migrations in the Round 4 acceptance matrix.
Production lanes run both Python modes, reject skips and require exact counts.
The aggregate independently reconstructs all eleven required lane bundles;
it cannot accept a missing lane, a different source/run, or its own receipt.

Run `python -B -m research.RHRC.integration.opica_composition.cli --help` for
the inspection, preparation, lane and aggregation entry points. The Actions
workflow provisions production isolation and preserves complete raw evidence.
`inspect` checks source scope only and must not be described as a proof build.

The service entry points are `freeze --experiment ...`, `inventory --snapshot
...`, `plan --snapshot ... --inventory ... --target D02_D05`, `run-one
--snapshot ... --proposals ... --journal ...`, `verify --snapshot ... --receipt
...`, `replay --journal ...`, and `export --journal ...`. Each takes an external
`--output` path. The experiment is an independently reviewed `ExperimentSpec`,
including all project/package/checker bytes and the actual prepared worker
environment. The source manifest and profile must validate before freezing.
Candidate plans cannot replace the target, constant table, menu or source.

The four actual-source research targets are registered separately as OPEN.
Their compiled definitions establish well-formed propositions only. Their
current approved proof menus are empty, so the runner reports its empty-menu
stop instead of assuming an independent inequality. The calibrated menu is
finite and deliberately incomplete as mathematical discovery; no search
exhaustiveness beyond the declared grammar/menu is claimed.

The mathematical inventory, K4/K5 source checks, closure alternatives and open
research obligations live alongside this package in `../opica_round4/`.
RH and Step 4 remain **OPEN**. Finite numerical enclosures, conditional
consumer lemmas and an accepted deduction runtime do not supply the missing
independent source estimate.
